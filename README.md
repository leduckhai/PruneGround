# PruneGround Project Page

Source of the project page for **PruneGround: Plug-and-play Spatial Pruning for 3D Visual Grounding**, served by GitHub Pages at [https://leduckhai.github.io/PruneGround/](https://leduckhai.github.io/PruneGround/).

The official source code, models, and benchmark implementations are available on the [`main` branch](https://github.com/leduckhai/PruneGround/tree/main).

The website is hosted on the [`gh-pages` branch](https://github.com/leduckhai/PruneGround/tree/gh-pages).

`index.html` is the main entry point. `styles.css` and additional CSS files define the website design, while `script.js` and other JavaScript modules provide interactive features, including the 3D Explorer and qualitative results showcase.

The `assets/` directory contains figures, logos, 3D meshes, and supporting visualization data.
